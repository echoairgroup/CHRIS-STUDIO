HOW THE PROJECTS TAKE SHAPE

Good ideas take
a bit of work.

The finished website is only one part of a project. There is also the planning, testing, rewriting and attention to the small things that make it useful.

PROCESS

A PRACTICAL APPROACH

Start with the reason for making something. Then keep checking that the result still solves the original problem.

01

THE IDEA

Work out what is missing.

Start with a question, a frustration or something worth exploring. Decide what the project should help someone do, and what it does not need.

PURPOSE
FIRST
02

THE PLAN

Choose the right format.

A simple website, a browser game and a desktop application have different needs. The structure should suit the project instead of forcing every idea into the same template.

RIGHT TOOL
FOR THE JOB
03

THE BUILD

Make the useful parts work.

Build the main experience first, connect the pieces it depends on and keep the code organised enough to change later.

MAKE IT
USEFUL
04

THE TEST

Try it like a visitor would.

Check the links, forms, navigation and mobile layout. Look for confusing wording and features that appear to work but do not actually do anything.

CHECK THE
DETAILS
05

THE NEXT ITERATION

Keep improving what matters.

Once a project is usable, feedback and real use help decide what should be improved next. A release can be complete and still have room to grow.
