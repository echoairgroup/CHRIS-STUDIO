PROJECT NOTES

01 / WINDOWS DESKTOP

TowerATC

A desktop companion concept for Microsoft Flight Simulator 2024. The focus is spoken tower communication as the main way to interact, with a real SimConnect connection to the simulator. It is designed as a Windows application rather than a website, so there is no browser version to visit.

02 / EARLY EXPERIMENTS

Aviation prototypes

A small group of early aviation projects and starter experiments. They helped explore ideas and technology, but they are not presented as finished products or public websites. The more developed aviation work is listed separately in the main project index.
